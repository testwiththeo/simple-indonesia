# simple-indonesia

Skill untuk menulis teks Bahasa Indonesia sederhana. Aturan diambil dari ASD-STE100 Simplified Technical English dan diadaptasi ke Bahasa Indonesia.

Gunakan skill ini untuk dokumentasi, README, runbook, pesan error, catatan rilis, dan penjelasan untuk pembaca di luar bidangmu.

## Cara pakai

Katakan "tulis bahasa Indonesia sederhana" atau "tanpa jargon". Untuk memeriksa teks yang sudah ada, katakan "check teks ini pakai simple-indonesia".

## Isi

- `SKILL.md` — aturan penulisan dokumen dan balasan, mode Plain dan Strict, contoh sebelum dan sesudah.
- `references/rule-catalog.md` — 53 aturan ASD-STE100 Issue 9 untuk mode periksa.
- `references/word-swaps.md` — pemetaan kata berlebih ke kata sederhana.
- `references/use-cases.md` — pola per jenis teks.
- `references/strict-vocabulary.md` — disiplin mode Strict.
