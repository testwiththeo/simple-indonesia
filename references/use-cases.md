# Kasus Penggunaan

Baca berkas ini bila menulis salah satu teks berikut. Setiap kasus punya mode dan pola.

| Teks | Mode | Pola |
|---|---|---|
| Pesan error | Prosedural | Nyatakan fakta dan penyebab. Satu kalimat. Jangan minta maaf. |
| Runbook | Prosedural | Langkah bernomor. Kondisi sebelum perintah. Sebutkan host dan flag. |
| Laporan insiden | Deskriptif | Urutan waktu, dampak, penyebab, tindakan. Fakta, bukan opini. |
| Catatan rilis | Deskriptif | Apa yang berubah, mengapa, apa yang harus dilakukan pembaca. |
| Pesan commit | Prosedural | Kalimat imperatif, di bawah 50 kata. Jelaskan apa, bukan bagaimana. |
| Teks UI | Prosedural | Kata kerja untuk tindakan. "Simpan", bukan "Penyimpanan". |
| Persiapan terjemahan | Plain | Hindari idiom. Satu makna per kata. |

Untuk semua: jangan gunakan emoji, tebal sebagai penekanan, atau heading lebih dari dua kalimat.
