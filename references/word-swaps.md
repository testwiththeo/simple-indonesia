# Pemetaan Kata (Word Swaps)

Ganti kata berlebihan dengan kata sederhana. Jika sebuah kata tidak membawa fakta, hapus saja.

| Tulisan asal | Tulis pengganti |
|---|---|
| sangat, sangat penting, krusial, vital | hapus, atau nyatakan fakta: "X penting karena Y" |
| komprehensif, lengkap | hapus atau "X mencakup A, B, C" |
| powerful, kuat | hapus |
| leverage, memanfaatkan | gunakan |
| robust, tangguh | hapus atau jelaskan cara kerjanya |
| seamless, mulus | hapus |
| however | tetapi |
| therefore | sebagai hasil |
| since (karena) | karena |
| perform | lakukan |
| avoid | cegah |
| repeat | lakukan lagi |
| acceptable | diizinkan |
| now | hapus |
| check, verify, confirm, validate, ensure | pastikan |
| config, settings, options | konfigurasi |
| dll., dst., etc. | sebutkan itemnya |
| e.g. | misalnya |
| i.e. | yaitu |
| also (berlebih) | hapus |
| in order to | untuk |
| it is worth noting | hapus |
